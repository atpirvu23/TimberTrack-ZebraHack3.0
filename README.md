# TimberTrack

Interactive map of **timber transports across Romania**, built using data from **SUMAL 2.0**, the national wood traceability system. Developed during the **ZebraHack 3.0** hackathon.

The project visualizes transport routes between origin and destination points, making wood flows easy to track and supporting transparency in the forestry sector.

## Features

- Interactive map of timber transports across Romania
- Visualization of routes between origin and destination points
- Built on real data from SUMAL 2.0
- Helps identify timber flows and supports forestry transparency

## Data source

- **SUMAL 2.0** – Romania's national system for tracking the origin and transport of wood

## Context

Developed in a team of 4 during the **ZebraHack 3.0** hackathon.
